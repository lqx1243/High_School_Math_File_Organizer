# 高中数学文件分类工具

面向 Windows 11 教师的本地桌面工具：读取教学资料的文件名和内容，使用 DeepSeek 提供分类建议，并以**复制**方式整理文件，始终保留原文件。

> 这是辅助整理工具。所有 AI 分类结果都应由老师在复制前人工复核。

## 下载与使用

请从 [Releases](https://github.com/lqx1243/High_School_Math_File_Organizer/releases) 下载最新的 Windows ZIP 包。

1. 解压整个 ZIP，保持其内部文件夹结构不变；
2. 双击 `HighSchoolMathFileOrganizer.exe`；
3. 在“准备资料”页面添加一个或多个待整理资料文件夹，并选择分类结果保存位置；
4. 填写历史截止年份和 DeepSeek API Key，点击“测试连接并获取模型”；若列表含 `deepseek-v4-flash` 会自动选择，否则手动选择一个模型，再开始扫描；
5. 软件会自动切换到“复核与复制”页面，核对分类建议后再确认复制。

运行电脑不需要安装 Python、Office 或 Tesseract OCR。

## 功能

- 支持 PDF、DOCX、PPTX，以及安装 Microsoft Office 时的旧 `.doc`、`.ppt`；
- 自动忽略 macOS 复制资料时产生的 `._*` 元数据文件，以及 Office 的 `~$*` 临时文件；
- 可添加多个资料文件夹，并递归扫描它们的所有子文件夹；即使同时添加父文件夹和子文件夹，同一文件也只会扫描和复制一次；
- 本机 OCR 处理扫描 PDF，以及图片为主的 Word/PowerPoint；
- 先判断一级分类，再仅在对应一级分类下判断二级分类；
- 结合文件名和正文内容；
- 历史文件、综合文件、无法分类文件独立归档；
- 低置信度结果自动留给人工处理；
- 表格中可双击修改任意分类；
- 安全复制、重名自动编号，并生成 `分类清单.csv`。
- 扫描进度会保存在本机缓存中；意外关闭后再次打开可恢复已完成的分类，并继续处理其余文件。
- 复制前会检查目标磁盘是否能容纳所有待复制内容，并固定预留 20 MB；复制按文件逐项在后台进行，可显示进度、停止后继续，并会跳过内容哈希相同的重复文件。
- 界面按“准备资料”“复核与复制”“规则与维护”分为三个页面，避免设置、操作与结果相互干扰。

## 分类标准

在“规则与维护”页面中，“自定义规则文件”默认留空。留空时程序会使用随软件放在 `defaults/category_rules.txt` 的默认模板；不需要在准备资料页面设置它。可直接输入路径或选择自己的 UTF-8 文本文件，并点击“检查规则”确认格式。点击“编辑当前规则”时，默认模板会先复制到本机设置目录中带版本号的副本，再作为自定义规则打开；旧版用户规则不会被覆盖。

格式如下：顶格文本为一级分类，缩进文本为该分类的二级分类；空行和以 `#` 开头的行会忽略。可在名称后用 `::` 写入分类说明，说明会随名称发送给 AI，帮助它区分相近分类。程序会检查 UTF-8 编码、空规则、重复的一级/二级分类、未归属一级分类的二级分类，以及空说明标记。

```text
# 这一行的内容会被忽略
函数与导数 :: 函数概念、性质、图像、应用以及导数相关内容
    函数及其性质 :: 定义域、值域、单调性、奇偶性与函数图像
    导数及其应用 :: 求导、单调性、极值、最值与切线问题
```

## 分类规则

1. 最后编辑年份早于界面所填年份的文件，进入“历史文件”，不调用 API。
2. 其余文件会结合文件名、正文和分类说明，先判断唯一一级分类，再在该一级分类下判断二级分类。
3. 无法可靠判断二级分类时，文件直接放入一级分类文件夹；涉及多个一级分类的内容进入“综合文件”。
4. 提取失败、不在规则范围内或低于设定百分比阈值的内容，进入“无法分类”。
5. 所有分类建议都应在复制前由老师复核；双击表格行可手动修改。

## 支持文件与 OCR

- 直接支持 PDF、DOCX、PPTX；安装 Microsoft Office 时也支持旧 `.doc`、`.ppt`。
- 扫描版 PDF 会自动尝试本机 Tesseract OCR；图片为主的 Word/PowerPoint 也会尝试识别图片内容。
- OCR 使用简体中文与英文语言包。数学公式的识别可靠性有限，公式型资料尤其需要人工复核。
- 自动忽略 macOS 的 `._*` 元数据文件和 Office 的 `~$*` 临时文件。

## 扫描缓存与复制恢复

缓存保存在本机设置目录，不保存 API Key。只有资料文件、分类标准、年份、阈值、模型、资料文件夹和结果目录一致时，已完成的分类与复制才会恢复；已修改文件会重新处理。点击“删除扫描缓存”只会清理本机进度、分类建议和复制状态，不会删除原文件、复制结果或 `分类清单.csv`。

## DeepSeek 与费用

每个非历史文件通常有一次一级分类调用；当一级分类明确且该一级存在二级分类时，才会有第二次调用。长文档最多发送前 18,000 个字符，文件名始终会作为判定依据。教学资料的文件名与文字摘录会发送至 DeepSeek API，请按账户额度管理费用。

## 注意事项

- 文件名和文字摘录会发送给 DeepSeek API；请自行管理 API Key 与账户额度。
- OCR 对图片中的数学公式并不完全可靠，尤其需要人工复核。
- 旧 `.doc`、`.ppt` 通过本机已安装的 Microsoft Word/PowerPoint 读取；若电脑未安装对应 Office，仍可先按文件名低置信度分类，或手动另存为新格式。
- “删除扫描缓存”只会删除本机的扫描进度、分类建议和复制状态；不会删除原文件、复制结果或 `分类清单.csv`。界面会显示缓存大小。复制失败原因也会写入缓存及 `分类清单.csv`。

## 开发与许可证

开发者可在 Windows 11 上运行 `build_windows.bat` 重新打包。脚本会自动从 `organizer/app.py` 读取 `APP_VERSION`，生成 `dist/HighSchoolMathFileOrganizer-windows-x64-v<APP_VERSION>/` 形式的发布文件夹；OCR 运行时已由 `vendor/tesseract` 提供。
