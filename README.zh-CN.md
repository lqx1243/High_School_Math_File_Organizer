# 高中数学文件分类工具

这是一个面向 Windows 11 老师的小型桌面工具：它扫描资料文件夹，先依据最后编辑年份分出历史文件，再用 DeepSeek 进行两阶段分类，最后**复制**文件到新目录。原文件不会移动或删除。

## 目前的分类规则

软件首次启动时，会将仓库自带的 `分类标准.txt` 复制为一份可编辑的本机默认模板；不写死在程序中。资料文件夹本身若有 `分类标准.txt`，软件会优先使用该文件：

```text
函数与导数
    函数及其性质
    导数及其应用

数列
    等差数列
    等比数列
```

- 顶格文本：一级分类。
- 前面有空格或 Tab 的文本：该一级分类的二级分类。
- 空行和以 `#` 开头的说明行会忽略。
- 修改完成后保存为 UTF-8 文本；下次扫描会自动使用新规则。

## 分类规则

1. 最后编辑年份早于界面所填年份的文件，进入 `历史文件`，不会调用 API。
2. 其余文件先根据**文件名和正文**选择唯一一级分类。
3. 仅在已选的一级分类下，再判断二级分类；二级无法可靠判断时，文件直接放在一级分类文件夹。
4. 无法归入唯一一级分类的资料，进入 `综合文件`。
5. 不在规则范围内、提取失败或低于置信度阈值的资料，进入 `无法分类`。
6. 每个结果都应由老师在软件表格中复核；可双击文件并手动修改分类。

## 支持的文件与 OCR

- 直接支持：`PDF`、`DOCX`、`PPTX`；若本机安装 Microsoft Office，也支持旧 `.doc`、`.ppt`。
- 扫描 PDF：正文太少时会将页面交给本机 OCR；图片为主的 DOCX/PPTX 也会尝试识别其中的图片。
- OCR 使用 Tesseract 的简体中文和英文语言包（`chi_sim` + `eng`）。OCR 很难完整识别数学公式，因此公式型资料尤其需要人工复核。
- 旧 `.doc`、`.ppt` 会通过本机已安装的 Microsoft Word/PowerPoint 读取；若未安装对应 Office，软件会提示并仍可依据文件名低置信度分类，也可手动另存为 `.docx`/`.pptx`。

## 首次使用（给老师）

1. 双击 `HighSchoolMathFileOrganizer.exe`。
2. 默认分类标准已经自动填入；可点击“编辑分类标准”修改它。若资料文件夹中有 `分类标准.txt`，软件会自动优先使用它。
3. 选择一个新的、空的“复制结果到”文件夹。
4. 输入历史截止年份。例如输入 `2021`，最后编辑年份为 2020 或更早的文件会进入历史文件。
5. 粘贴 DeepSeek API Key。程序会优先存入 Windows 凭据管理器，而不会写进普通设置文件。
6. 点击“扫描并生成分类建议”，核对分类结果；双击表格项目可改分类。
7. 点击“确认后复制分类结果”。结果文件夹中会有分类目录和 `分类清单.csv`。

## DeepSeek 与费用

每个非历史文件通常会进行 1 次一级分类 API 调用；当一级分类明确且该分类有二级分类时，才会再进行第 2 次调用。长文档会截取前 18,000 个字符，文件名始终会进入提示词。默认模型为 `deepseek-v4-flash`，可在设置文件中按未来 API 变化调整。

教学资料的文件名和文字摘录会发送至 DeepSeek API；使用前请确认老师接受这一点并按 DeepSeek 的账户额度管理费用。

## 打包 Windows 安装版

在 Windows 11 的开发电脑中双击或执行 `build_windows.bat`，即可生成 `dist/HighSchoolMathFileOrganizer/HighSchoolMathFileOrganizer.exe`。脚本直接使用 `python` 命令，不依赖额外的 `py` 启动器。

为了做到老师端真正开箱即用，发布包已包含以下 OCR 运行文件：

1. `tesseract.exe`；
2. `tessdata/chi_sim.traineddata`；
3. `tessdata/eng.traineddata`。

如果 OCR 不可用，软件会安全提示并继续用文件名/可读文字分类；老师电脑无需自行安装 OCR。
